1. Imports: `requests`, `logging`, `typing`, `decimal.Decimal`, `requests.adapters.HTTPAdapter`, `urllib3.util.retry.Retry`, `src.kalshi.auth.KalshiAuth`, `src.kalshi.auth.dollars_to_cents`.

2. `logger = logging.getLogger(__name__)`

3. Define `class KalshiClient`:

   **`__init__(self, base_url: str, key_id: str, private_key_path: str)`:**
   - `self.base_url = base_url`
   - `self._auth = KalshiAuth(key_id, private_key_path)`
   - `self._session = self._build_session()`

   **`_build_session(self) -> requests.Session`:**
   - Create `requests.Session()`
   - Set `session.auth = self._auth`
   - Create `Retry(total=3, backoff_factor=1, status_forcelist=[429, 500, 502, 503, 504], allowed_methods=["GET", "POST", "DELETE"], raise_on_status=False)`
   - Mount `HTTPAdapter(max_retries=retry)` on `"https://"`
   - Set `session.headers.update({"Content-Type": "application/json", "Accept": "application/json"})`
   - Return session

   **`_get(self, path: str, params: dict | None = None) -> dict`:**
   - `resp = self._session.get(f"{self.base_url}{path}", params=params)`
   - `resp.raise_for_status()`
   - `return resp.json()`

   **`_post(self, path: str, json: dict | None = None) -> dict`:**
   - `resp = self._session.post(f"{self.base_url}{path}", json=json)`
   - `resp.raise_for_status()`
   - `return resp.json()`

   **`_delete(self, path: str) -> dict`:**
   - `resp = self._session.delete(f"{self.base_url}{path}")`
   - `resp.raise_for_status()`
   - `return resp.json()`

   **Market Discovery (R1.3):**

   `get_markets_by_series(self, series_ticker: str, status: str = "open", limit: int = 200) -> list[dict]`:
   - Initialize empty list `markets = []`
   - `params = {"series_ticker": series_ticker, "status": status, "limit": limit}`
   - Cursor loop: call `self._get("/markets", params=params)`, extend `markets` with `resp["markets"]`, check `cursor = resp.get("cursor", "")`, break if empty, else set `params["cursor"] = cursor`
   - Return `markets`

   `get_market(self, ticker: str) -> dict`:
   - `return self._get(f"/markets/{ticker}")["market"]`

   **Event Discovery (R1.4):**

   `get_event(self, event_ticker: str) -> dict`:
   - `return self._get(f"/events/{event_ticker}")["event"]`

   **Orderbook (R1.5):**

   `get_orderbook(self, ticker: str) -> dict`:
   - `resp = self._get(f"/markets/{ticker}/orderbook")`
   - Parse `resp["orderbook_fp"]` — the key contains `"yes_dollars"` and `"no_dollars"` arrays
   - Each entry is `[price_str, quantity_str]`
   - Convert: `yes_bids = [(dollars_to_cents(p), float(q)) for p, q in ob.get("yes_dollars", [])]`
   - Same for `no_bids` from `"no_dollars"`
   - Return `{"yes_bids": yes_bids, "no_bids": no_bids, "raw": resp}`

   **Order Placement (R1.6):**

   `place_limit_order(self, ticker: str, side: str, action: str, price_cents: int, count: int, post_only: bool = True) -> dict`:
   - Build payload: `{"ticker": ticker, "side": side, "action": action, "type": "limit", "yes_price": price_cents if side == "yes" else (100 - price_cents), "count": count, "post_only": post_only, "time_in_force": "good_till_canceled"}`
   - `return self._post("/portfolio/orders", json=payload)["order"]`

   **Order Management (R1.7):**

   `cancel_order(self, order_id: str) -> dict`:
   - `return self._delete(f"/portfolio/orders/{order_id}")`

   `get_orders(self, status: str | None = None) -> list[dict]`:
   - `params = {}; if status: params["status"] = status`
   - `return self._get("/portfolio/orders", params=params).get("orders", [])`

   `get_fills(self, ticker: str | None = None, limit: int = 100) -> list[dict]`:
   - `params = {"limit": limit}; if ticker: params["ticker"] = ticker`
   - `return self._get("/portfolio/fills", params=params).get("fills", [])`

   **Portfolio State (R1.8):**

   `get_balance(self) -> dict`:
   - `resp = self._get("/portfolio/balance")`
   - Return `{"balance_cents": resp["balance"], "portfolio_value_cents": resp.get("portfolio_value", 0)}`

   `get_positions(self, status: str | None = None) -> list[dict]`:
   - `params = {}; if status: params["settlement_status"] = status`
   - `return self._get("/portfolio/positions", params=params).get("market_positions", [])`

   `get_settlements(self, limit: int = 100) -> list[dict]`:
   - `return self._get("/portfolio/settlements", params={"limit": limit}).get("settlements", [])`

   **Exchange Status (utility):**

   `get_exchange_status(self) -> dict`:
   - `return self._get("/exchange/status")`
