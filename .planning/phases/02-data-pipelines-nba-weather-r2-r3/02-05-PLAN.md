    **Create `tests/data/test_pipeline.py`** first (RED). Mock all imported data functions. Test argument parsing and dispatch logic only — no live API calls.

    **Create `src/data/pipeline.py`** (GREEN) per D-09 with:

    1. **`parse_args(argv: list[str] | None = None) -> argparse.Namespace`**
       - `argparse.ArgumentParser(description="Kalshi Bot Data Pipeline")`

       - Return parsed args

       - Log "Starting historical data refresh..."
       - Call `fetch_historical_results()` — log result count

       - Log "Historical refresh complete"

       - Log "Starting daily data refresh..."
       - Call `get_todays_schedule()` — log game count
       - Call `get_team_stats()` — log team count
       - For each station in `station_map.STATIONS`: call `get_nws_forecast(lat, lon)` — log forecast period count
       - Log "Daily refresh complete"

    4. **`main(argv: list[str] | None = None) -> None`**
       - Parse args
       - If `args.refresh_history`: call `run_historical_refresh()`
       - Else: call `run_daily_refresh()`

    5. **`if __name__ == "__main__": main()`**

    Module-level: `logger = logging.getLogger(__name__)`
    Runnable as: `python -m src.data.pipeline --refresh-history`
