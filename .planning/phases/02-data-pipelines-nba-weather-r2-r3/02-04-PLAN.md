  Fields: GAME_DATE, MATCHUP, WL, MIN, PTS, REB, AST, STL, BLK, TOV, FGM, FGA, FG3M, FG3A, FTM, FTA, PLUS_MINUS

- LeagueDashPlayerStats: season, per_mode_simple="PerGame" -> per-game averages
- LeagueDashPtDefend: defense_category, season -> opponent defensive matchup stats

- URL: https://site.api.espn.com/apis/site/v2/sports/basketball/nba/injuries
- Returns JSON with "injuries" key — list of team injury entries
- Each: athlete name, team, status ("Out", "Questionable", "Day-To-Day"), injury type

nba_api fallback: LeagueInjuryReport(season="2024-25").get_normalized_dict()
