NWS API patterns:
- Step 1: GET /points/{lat},{lon} -> properties.gridId, gridX, gridY, forecast, forecastHourly, forecastGridData
- Step 2a: GET /gridpoints/{office}/{gridX},{gridY}/forecast -> properties.periods (12-hour)
- Step 2b: GET /gridpoints/{office}/{gridX},{gridY}/forecast/hourly -> hourly periods
- Step 2c: GET /gridpoints/{office}/{gridX},{gridY} -> raw griddata (temperature, probabilityOfPrecipitation time series)
- validTime format: "2026-03-29T18:00:00+00:00/PT1H" — split on "/" to get start_time and duration
- User-Agent header: "(kalshi-bot, {contact_email})" — required

NOAA CDO pattern:
- GET https://www.ncei.noaa.gov/cdo-web/api/v2/data with token header
- params: datasetid=GHCND, stationid=GHCND:USW00094728, datatypeid=TMAX,TMIN,PRCP, startdate, enddate, limit=1000, units=standard
- TMAX/TMIN values in tenths of degree — divide by 10 for Fahrenheit
- Max 1000 records per request — paginate with offset
