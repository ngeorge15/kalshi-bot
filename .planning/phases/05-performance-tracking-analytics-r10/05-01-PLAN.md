## Task 1 — Schema v3

`src/db/schema.sql`, appended (keep the v1/v2 sections untouched):

- `feature_importance` — `(model_name, model_version, feature_name, importance, recorded_at)`,
  `UNIQUE(model_name, model_version, feature_name)` so re-recording a version is idempotent.
- `price_observations` — `(ticker, market_type, observed_at, yes_bid_cents, yes_ask_cents,
  mid_price_cents, model_prob, edge_cents, hours_to_close)`.
  `hours_to_close` is REAL and nullable (unknown close time is legal).
- Indexes: `idx_feature_importance_model`, `idx_price_obs_ticker`, `idx_price_obs_market_type`.
- `INSERT OR IGNORE INTO schema_version (version) VALUES (3);`

## Task 3 — Deterministic seeder

`scripts/seed_test_data.py`, importable *and* runnable as a CLI.

`seed_database(db, n_days=7, seed=42, trades_per_day=12) -> dict` writes linked
`predictions` -> `trades` -> `outcomes` rows plus a `price_observations` series per ticker,
and returns a ground-truth manifest the tests assert against.

Ground truth baked in per market type (D5-07: five types spanning three domains):

| market_type | Domain | Planted pattern |
|---|---|---|
| `games` | NBA | Well calibrated, mildly profitable |
| `props` | NBA | **Overconfident by 8%** — predicted probs sit 0.08 above realised frequency |
| `temperature` | Weather | Well calibrated, profitable |
| `precipitation` | Weather | **Consistently losing** — negative P&L |
| `cbb_games` | *Third domain* | Small sample; exists purely to prove no code assumes {nba, weather} |

Requirements:
- Seeded `random.Random(seed)` only — no global `random`, no `numpy.random`. Same seed must
  produce a byte-identical database.
- Timestamps ISO 8601 UTC, spread backwards over `n_days` (CONVENTIONS: DB timestamp rule).
- Money in integer cents (CONVENTIONS).
- `outcomes.prediction_id` and `outcomes.trade_id` populated so D5-06's preferred join path is
  actually exercised by the tests, not just the ticker fallback.
- `price_observations` per ticker: an edge that **decays** toward 0 as `hours_to_close` -> 0 for
  most tickers, and a control group whose edge **persists**, so 05-03 has both signals present.
- CLI: `python -m scripts.seed_test_data --db data/test_seed.db --days 7 --seed 42`.
  Refuse to run against a non-empty `trades` table unless `--force` (guardrail: never silently
  contaminate a real ledger).
